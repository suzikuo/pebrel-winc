# Pebrel Winc 2.5.11

## English

### Improved

- Improved focus distinction between the main terminal and the Scratch Terminal. When the Scratch Terminal is open, the inactive surface dims with the same inactive-pane dimming setting used by split panes, the focused Scratch Terminal highlights its border with the theme accent color, and split-pane focus indicators in the main terminal clear while the Scratch Terminal is focused.
- Improved sidebar tab group startup behavior so restored sidebar groups start collapsed by default and expand when clicked.

## 简体中文

### 改进

- 改进主命令行与临时命令行之间的焦点区分。打开临时命令行时，未聚焦的一侧会复用分屏的非聚焦压暗遮罩，临时命令行聚焦时边框以主题强调色高亮；焦点在临时命令行时，主命令行分屏的聚焦指示同步熄灭。
- 改进侧边栏标签分组的启动恢复行为，恢复会话时侧边栏分组默认保持折叠，点击分组后再展开。
