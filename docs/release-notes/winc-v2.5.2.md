# Pebrel Winc 2.5.2

## English

### Fixed

- Fixed right-clicking a tab so it opens the tab menu without switching tabs.

### Improved

- Improved the sidebar by adding space between groups while keeping tab spacing within each group.
- Improved the group’s `+` button so it opens the Ctrl+K picker and adds the selected terminal to that group.
- Improved local Windows packaging and publishing by capping each build started from the menu at 80% CPU usage.

## 简体中文

### 修复

- 右键点击标签只打开该标签的菜单，当前标签保持不变。

### 改进

- 加大左侧栏的组间留白，组内标签保持原有行距。
- 分组的 `+` 按钮打开 Ctrl+K 选择器，选定的终端会在该组内新建。
- 从 Windows 菜单启动打包或发布时，每次构建的 CPU 使用率上限为 80%。
