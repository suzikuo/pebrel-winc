# Pebrel Winc 2.5.7

## English

### Fixed

- Fixed Settings card and sidebar backgrounds remaining visible at 0% window opacity. In **Settings → Appearance → Interface**, enable **Settings follows window opacity** to show the background through Settings cards, navigation, and the Plugin Center while keeping text and controls visible. The switch is off by default. Addresses [#1077](https://github.com/Kuddev/nebula/issues/1077).

## 简体中文

### 修复

- 修复窗口背景不透明度为 0% 时，设置页卡片和侧栏底色仍然可见的问题。在「设置 → 外观 → 界面」开启「设置页跟随窗口背景不透明度」后，设置页卡片、侧栏和插件中心的底色会跟随窗口不透明度，文字和控件保持可见。开关默认关闭。对应 [#1077](https://github.com/Kuddev/nebula/issues/1077)。
