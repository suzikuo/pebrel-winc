# Pebrel Winc 2.5.8

## English

### Fixed

- Fixed windows behind Pebrel showing through Settings at 100% window opacity when a translucent wallpaper covers the window. Settings keeps the wallpaper visible and follows the window opacity slider when **Settings follows window opacity** is enabled.

## 简体中文

### 修复

- 修复半透明壁纸覆盖窗口时，设置页在窗口不透明度为 100% 的情况下仍会透出背后窗口的问题。设置页保留壁纸显示，开启「设置页跟随窗口背景不透明度」后，底色仍随窗口不透明度滑块调节。
