# Pebrel Winc 2.5.4

## English

### Added

- Added **Plugin Community** under **Settings → Plugins**. Browse Winc and Scratch Terminal from the [community repository](https://github.com/suzikuo/pebrel-winc-plugins), review the permissions, and confirm installation in Pebrel Winc.

### Improved

- Improved Winc plugin setup. Select your existing `winc.exe` during installation. The File Explorer button opens the focused Windows or WSL folder using the Windows shell, without a separate helper program.

## 简体中文

### 新增

- **设置 → 插件**新增**插件社区**。可在 Pebrel Winc 内浏览[社区仓库](https://github.com/suzikuo/pebrel-winc-plugins)的 Winc 和临时终端，审阅权限后确认安装。

### 改进

- 简化 Winc 插件的安装流程，安装时选择本机已有的 `winc.exe` 即可。文件夹按钮通过 Windows 打开当前 Windows 或 WSL 窗格的目录，无需额外的辅助程序。
